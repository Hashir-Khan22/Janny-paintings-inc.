# Janney Painting Inc. - Modern Industrial Website

Stunning, modern, highly interactive website built for **Janney Painting Inc.**, an industrial painting and abrasive sandblasting contractor based in Manchester, Maryland, in business since 1982 (43+ years), specializing in abrasive blasting and structural steel coating for heavy industry.

## Key Features
- **Official Brand Identity**: Swapped official logo badge with twin smokestacks, industrial elevator truss, and bolted steel plate.
- **Color Scheme**: Safety yellow (`#F5B700`), deep charcoal/black (`#0A0B0D`, `#141619`), steel-gray textures, and high-contrast typography (`Oswald` & `Inter`).
- **Complete Dropdown Sub-Page Navigation**:
  - **Industrial Services**: Structural Steel, Warehouse, Interior Walls/Ceilings/Floors, Secondary Containment, Corrugated Steel Ceiling, Large Machinery & Equipment.
  - **Industrial Markets**: Tank Containment, Factory & Warehouse, Water & Wastewater, Potable Water, Fertilizer, Food Processing, Cement, Petrochemical.
  - **Aggregate Services**: Structural Steel, Quarry, Asphalt Plant, Ready Mix Plant, Grain Elevator, Feed Mill, Heavy Machinery.
  - **Aggregate Markets**: Quarries & Stone Crushing, Asphalt Processing, Ready Mix Concrete, Grain Silos, Feed Mills, Cement Terminals, Screens.
  - **Cities We Serve**: Baltimore MD, Dover DE, Harrisburg PA, Lancaster PA, Norfolk VA, Pittsburgh PA.
- **Interactive Sub-Page Specification Viewer**: Modal showing engineering specs, SSPC surface prep standards, primary coating systems, and OSHA/MSHA safety credentials.
- **Direct Search Modal**: Instant autocomplete search across all services, markets, and cities.
- **Animated Counter Bar**: Dynamic numbers counting up (43+ Years, 2,546+ Projects, 100% OSHA & MSHA Part 46 Compliance, 100% DEP Approved Products).
- **Hero Project Spotlights**: Rotating showcase for Feed Mill Painting, Tank Coatings, Bridges, and Quarries.
- **Industrial Painting News**: 6-card responsive grid matching the mockup (including Rust-Oleum brand partnership badge) with slide-up article reader modal.
- **Advantage Split CTA**: Equipment sunset video thumbnail with modal player and quote trigger.
- **Competitive Pricing**: Interactive plus/minus accordion checklist.
- **Contact Us Section**: Split yellow contact form with dynamic math captcha, client-side validation, success toast, and embedded Google Map of Manchester, MD.
- **Mobile Responsive**: Sticky header, mobile drawer menu with collapsible accordions, and floating one-tap call/quote bar.

## Technology Stack
- HTML5, Vanilla CSS3 (Custom Properties / Design Tokens), Vanilla JavaScript (ES Modules)
- Vite (Dev server & production bundling)

## Development Setup
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```
